# Lumen2D — লাইটিং সিস্টেম (কোয়ালিটি টিয়ার)

> এই ফাইল লাইটিং-এর "সত্যের উৎস"। কোডে টিয়ার-সেটিং এই টেবিল অনুযায়ীই বাস্তবায়িত হবে।
> স্ট্যাটাস: টেবিলটি নির্ধারিত; বাস্তবায়ন মাইলস্টোন অনুযায়ী (M5, M6, M12) এগোবে।

## পাইপলাইন

সিন (HDR অফস্ক্রিন) → লাইটিং পাস (হাফ-রেজোলিউশন) → কম্পোজিট → পোস্ট-প্রসেস → টোন-ম্যাপ আউটপুট।

## নিয়ম

- `experimental_gi` ডিফল্ট **অফ**; শুধু High/Ultra-তে চলবে।
- FPS বাজেট ছাড়ালে প্রথমে লাইটিং রেজোলিউশন, তারপর ক্যাসকেড কমবে — ফিচার মুছে ফেলা হবে না।
- টিয়ার `project.lumen.json` (`"lighting": {"quality": "medium"}`) বা রানটাইম API-তে সেট করা যাবে।

## পারফরম্যান্স বাজেট (গ্রহণযোগ্যতা)

- মিড-রেঞ্জ Android (Snapdragon 695 / Mali-G57) — নমুনা "LightingShowcase", 1080p, **Medium** টিয়ারে স্থিতিশীল 60 FPS।
- বাজেট ডিভাইসে **Low** টিয়ারে 60 FPS।
- প্রোফাইলিং কাউন্টার (লাইট সংখ্যা, শ্যাডো-ম্যাপ সময়, ড্র-কল) FPS ওভারলেতে।
